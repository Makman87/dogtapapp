# DogTapApp

DogTapApp is a mobile application (in development, launching Q1 2027) that
connects users with adoptable shelter dogs and generates donations for animal
shelters and rescue organizations.

## What it does

Users engage with real adoptable dogs from shelters near them. Each interaction
generates revenue that is donated to support shelter animals, granted through
the Petfinder Foundation — a 501(c)(3) public charity and the app's charitable
partner.

The goal is to make helping shelter animals as low-friction as possible: users
contribute in seconds, and the cumulative impact funds food, medical care, and
other needs for adoptable pets nationwide.

## Data

The app displays adoptable pet listings — photos, descriptions, breed, and
shelter/location details — sourced from a live adoptable-pet data API.

## Status

Pre-launch. Development begins following confirmation of the app's data source.
Target launch: Q1 2027
